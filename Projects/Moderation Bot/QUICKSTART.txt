QUICK START GUIDE
=================

Getting your moderation bot up and running in 5 minutes.

STEP 1: Install Python
-----------------------
Download Python 3.8+ from python.org if you don't have it.
Check your version: python --version

STEP 2: Install Dependencies
-----------------------------
Open terminal in the bot folder and run:
  pip install -r requirements.txt

Wait for all packages to install.

STEP 3: Get Your API Keys
--------------------------
You need two things:

Discord Bot Token:
  1. Go to discord.com/developers/applications
  2. Click "New Application"
  3. Go to "Bot" tab
  4. Click "Add Bot"
  5. Copy the token

Gemini or Any Other Api Key (for AI moderation):
  1. Go to makersuite.google.com/app/apikey
  2. Click "Create API Key"
  3. Copy the key

STEP 4: Run Setup
-----------------
Run: python setup.py

Enter your:
  - Bot token
  - Gemini API key
  - Log channel ID (right click channel > Copy ID)
  - Admin role ID (optional)
  - Mod role ID (optional)
  - Command prefix (default is !)

STEP 5: Invite Bot
------------------
1. Go to discord.com/developers/applications
2. Select your application
3. Go to OAuth2 > URL Generator
4. Select scopes: bot, applications.commands
5. Select permissions:
   - Kick Members
   - Ban Members
   - Moderate Members
   - Manage Messages
   - View Channels
   - Send Messages
   - Embed Links
6. Copy the generated URL and open it
7. Select your server and authorize

STEP 6: Start Bot
-----------------
Run: python main.py

You should see "Bot is ready!" in the console.

STEP 7: Test It
---------------
In your Discord server, try:
  /warn @someone testing
  /addfilter badword
  /warnings

That's it! Your bot is now protecting your server.

TROUBLESHOOTING
---------------
Bot won't start:
  - Check your token in config.json
  - Make sure all dependencies installed

Commands not showing:
  - Wait a few minutes for Discord to sync
  - Make sure bot has applications.commands scope

Bot can't kick/ban:
  - Check bot's role is above target's role
  - Verify bot has proper permissions

AI filter not working:
  - Check Gemini API key is valid
  - Check logs folder for errors

TIPS
----
- Set up the log channel first so you can see all actions
- Add mod/admin role IDs for better permission control
- Start with a few filtered words and add more as needed
- Adjust spam thresholds in config.json if too sensitive
- Check logs folder regularly for any issues
